## About

365 Days Tracker helps you build a simple visual record of the things you want to make time for. Create separate trackers for different goals, mark each day, add notes and review your progress through monthly and overall statistics.

No sign-up or account is required.

## Features

- **Multiple trackers** — create and manage separate trackers for habits, studies, hobbies, skills and personal projects.
- **Custom date ranges** — choose your own start and end dates; a calendar year is used by default.
- **Simple daily marking** — cycle through three states: unmarked, completed and paused/missed.
- **Daily notes** — save a short reflection or note for a selected date.
- **Progress overview** — see completed, paused/missed and unmarked days, along with completion percentage.
- **Monthly and overall statistics** — review progress across months and calendar years.
- **Optional streak tracking** — enable current and best consecutive-day streaks for a tracker.
- **Personalisation** — choose light, dark or system appearance, an accent colour and calendar weekday headings.
- **Backup and restore** — download a JSON backup and restore it later.
- **Local-first storage** — tracker data is saved in the browser on your device.
- **Responsive layout** — designed to work on desktop and mobile screens.

## Getting started

1. Open the [live tracker](https://simplesoftwares.github.io/365-Days-Tracker/).
2. Create a tracker and give it a name.
3. Choose its category, date range and any optional settings.
4. Open the calendar and tap a date to change its status.
5. Select a date to add a daily note.
6. Visit the overview and statistics pages to review your progress.

You can create different trackers for different parts of your life. For example: reading, music practice, revision, exercise, learning a skill or working on a personal project.

## Daily status

| Status | Meaning |
| --- | --- |
| Grey | Unmarked |
| Green | Completed |
| Red | Paused / missed |

Tap a date to move to the next status.

## Privacy and data

365 Days Tracker does not require an account. Your tracker information is stored in your browser on your device, using browser storage. The app also keeps a secondary recovery copy in IndexedDB in the same browser profile where supported.

The app does not upload your tracker data to its own servers.

**Important:** browser storage is not a substitute for a separate backup. Clearing browser data, changing browsers or devices, or losing access to the browser profile can make locally stored information unavailable. Use **Download backup** regularly and keep the JSON file somewhere safe.

Anyone with access to your unlocked device or browser profile may be able to view your trackers.

Read the in-app **Privacy & data** section for the app's privacy explanation.

## Backup and restore

- Open the app menu and choose **Download backup** to export your trackers and preferences as a JSON file.
- Choose **Restore backup** to import a previously downloaded JSON file.
- Restoring replaces the trackers and preferences currently stored in that browser, so keep a copy of your latest data before restoring.

## Technology

365 Days Tracker is built with:

- HTML
- CSS
- Vanilla JavaScript
- Browser `localStorage`
- IndexedDB for a secondary recovery copy

The app is a static, client-side project and does not require a separate application server or database.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

The tracker is designed to run as a static website. GitHub Pages hosts the public version.
